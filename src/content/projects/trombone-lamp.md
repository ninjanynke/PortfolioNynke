## Method

This is the trombone, all finished and hung up on the wall. To get to this point, I bought an old trombone off of Marktplaats (a Dutch market place website). It was not in a condition anymore to be played, so it was perfect to use as a hanging piece. The original owner gave the trombone a new metal paint finish, which unfortunately came off a bit due to the tight packaging with sticky tape. I patched it up with the same paint.

Since the trombone has multiple ''open ends'' it was easy to wire it. We hung it up with a special bracket that fit the handle nicely. According to my brother, not only he, but all his friends find it a pretty cool piece: which is always flattering to hear. All in all, it was a very fun and easy project to do.
